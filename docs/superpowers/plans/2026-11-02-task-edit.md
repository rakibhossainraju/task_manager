# Task Detail & Edit Modal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a comprehensive Task Detail and Edit Modal allowing users to inspect, modify, move, and delete existing tasks on the Kanban board.

**Architecture:** Add domain method `BoardState::update_task` with title validation, attribute mutation, and status column transfers. Mount an `EditTaskModal` dialog at root level in `TaskManager` managed via an `EditingTask(Option<Uuid>)` context triggered on card clicks.

**Tech Stack:** Rust 2024, Dioxus 0.7, Tailwind CSS, Chrono, Uuid

**Spec:** `docs/superpowers/specs/2026-11-02-task-edit-design.md`

## Global Constraints
- Pure domain logic with comprehensive unit tests for `update_task`.
- Zero compiler warnings or errors (`cargo check && cargo test`).
- Strict Single Responsibility Principle per file.
- Clean RSX markup with accessible keyboard shortcuts (<kbd>Esc</kbd> to dismiss, <kbd>Enter</kbd> / <kbd>Ctrl+Enter</kbd> to save).

## Review Focus
1. Validation of empty/whitespace titles: attempting to save an empty or whitespace-only title must return an error and preserve existing state.
2. Inter-column status movement via edit modal: changing the status dropdown correctly moves the task to the selected group.
3. Updated timestamp tracking: editing a task sets `task.updated_at` to the current local time.
4. Nonexistent task/group safety: invalid task or target group UUIDs return safe errors without panicking.
5. Delete action from modal: clicking delete in the modal removes the task and closes the modal cleanly.

- [ ] **Step 3: Implement `update_task` in `BoardState`**

In `src/models/board.rs`:
- Trim title; if empty, return `Err("Task title cannot be empty")`.
- Find task across all groups (record source group index and task index). If not found, return `Err("Task not found")`.
- If `target_group_id` is provided and differs from source group:
  - Verify target group exists. If not, return `Err("Target group not found")`.
  - Remove task from source group.
  - Update `title`, `description`, `priority`, and `updated_at = Some(Local::now())`.
  - Push task to target group.
- Else:
  - Update task in-place: `title`, `description`, `priority`, and `updated_at = Some(Local::now())`.
- Return `Ok(())`.
